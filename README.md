### Тендерлік сатып алуларға арналған интеллектуалды AI-платформа

**TenderMind AI** — өндірістік кәсіпорындар мен кәсіпкерлерге тендерлік сатып алу процестерін автоматтандыруға, техникалық талаптарды талдауға, жеткізушілерді салыстыруға және қаржылық тәуекелдерді бағалауға көмектесетін жасанды интеллект негізіндегі веб-платформа.

Жобаның мақсаты — өндірістік сатып алуларды **жылдам, тиімді, ашық және экономикалық тұрғыдан негізделген** процеске айналдыру.

**Бағыты:** AIStartUpIdeas — өндірістегі мәселелерді шешуге арналған инновациялық AI-стартап.


 Жоба шешетін мәселе

Өндірістік кәсіпорындар жабдықтарды, қосалқы бөлшектерді, шикізат пен қызметтерді сатып алу барысында бірнеше қиындыққа тап болады:

- Тендерлік құжаттардың күрделілігі және көп уақыт алуы.
- Техникалық талаптарға сәйкес жеткізушілерді табудың қиындығы.
- Ұсыныстарды қолмен салыстыру кезінде қателердің туындауы.
- Логистика мен қосымша шығындардың толық есептелмеуі.
- Төлем мерзімдеріне байланысты қаржылық тәуекелдер.
- Бірнеше бағдарлама арқылы жұмыс істеудің қолайсыздығы.

**TenderMind AI** осы процестерді бір цифрлық кеңістікке біріктіруге бағытталған.

Жобаны жергілікті іске қосу

 1. Репозиторийді жүктеу

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

`USERNAME/REPOSITORY` орнына өз репозиторийіңіздің нақты мекенжайын жазыңыз.

### 2. Виртуалды ортаны құру

Windows PowerShell:

```powershell
py -m venv .venv
```

### 3. Қажетті кітапханаларды орнату

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. AI API-ключін орнату

Жобаның негізгі қалтасында `.env` файлын жасаңыз:

```env
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4.1-mini
```

OpenAI API-ключін алу:

https://platform.openai.com/api-keys

**Қауіпсіздік:** `.env` файлын GitHub репозиторийіне жүктемеңіз. API-ключтерді ешкімге жарияламаңыз.

### 5. Серверді іске қосу

Егер жобаның негізгі сервер файлы `server.py`, ал FastAPI объектісі `app` деп аталса:

```powershell
.\.venv\Scripts\python.exe -m uvicorn server:app --reload
```

Браузерден ашыңыз:

```text
http://127.0.0.1:8000
```

Ескерту: нақты іске қосу командасы репозиторий құрылымына байланысты өзгеруі мүмкін.
