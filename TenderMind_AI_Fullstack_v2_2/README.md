# TenderMind AI 2.2 — HTML/CSS/JavaScript + Python

**Новая веб-версия с прежним функциональным Python-ядром.** Оформление: HTML, CSS, JavaScript. Сервер: FastAPI. База данных: SQLite, формат совместим с предыдущей Streamlit-версией v0.5.

## Запуск на Windows 10/11

1. **Распакуйте весь ZIP**, а не открывайте файлы прямо внутри архива.
2. Откройте папку `TenderMind_AI_Fullstack_v2_2` (именно внутри неё лежат `run.py`, `requirements.txt`, `web/`).
3. Дважды щёлкните `START_WINDOWS.bat`. Он использует установленный `uv`, ставит Python 3.12 и зависимости.
4. Сайт автоматически откроется в браузере (Edge подходит) по адресу **http://127.0.0.1:8501**. Пока сайт открыт, окно сервера должно оставаться запущенным.

Если `uv` не найден, сначала установите его: https://docs.astral.sh/uv/getting-started/installation/ — затем повторите запуск.

**Ручные команды PowerShell**, находясь в папке с `requirements.txt`:

```powershell
$env:Path = "$env:USERPROFILE\.local\bin;$env:Path"
uv python install 3.12
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

> `index.html` отдельно двойным щелчком **не запускайте**: новая версия получает данные через Python API.

### AI-ключ

В разделе **Настройки** можно вставить API-ключ OpenAI или Gemini (хранится только в оперативной памяти Python-сервера до остановки; в браузере и SQLite не сохраняется). Или скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY` либо `GEMINI_API_KEY`. **Никому не отправляйте ключ и не загружайте `.env` в GitHub.** На AI-запросы может списываться платёж у провайдера.

## Перенос данных из предыдущих версий

**Из Streamlit v0.5 (SQLite):** остановите оба проекта, создайте резервную копию старой `data/projects.sqlite3`, затем скопируйте этот файл в **эту** папку `data/projects.sqlite3` *до первого запуска новой версии*. Движки используют тот же формат БД. Ваши сохранённые тендеры и данные закупок появятся в интерфейсе. Когда вы редактируете тендер в новом интерфейсе, соответствующие JSON-поля обновляются в той же таблице проектов.

**Из самостоятельной HTML v1 (localStorage):** в предыдущей версии скачайте `Все тендеры JSON`, затем здесь откройте **Настройки → Импортировать проекты из JSON**. Проекты с совпадающими ID будут обновлены. Прямой импорт localStorage из другого сайта не выполняется без разрешения пользователя.

Если вы начинали новый проект с пустой папкой, новая БД создаётся автоматически с шестью учебными тендерами.

## Важные ограничения

- Это **локальный однопользовательский MVP**, сервер только на `127.0.0.1`. Для размещения в интернете обязательны авторизация, ограничения по пользователям, защита API и HTTPS.
- PDF без встроенного текста (сканы) **не распознаются**: OCR отсутствует, как и в предыдущем проекте.
- Supplier Hunter ищет **сайты/сниппеты**, а не автоматически подтверждённые цены или наличие. SmartMatch тоже выдаёт **предварительную** оценку. Для окончательных закупок сведения необходимо проверять вручную.
- SplitBuy оптимизирует **одну товарную позицию за расчёт**, как в старом Python-ядре, до 14 подходящих поставщиков. Флаг неподтверждённых предложений отключён по умолчанию.
- CashGuard — упрощённая модель денежных потоков без налогов, штрафов, гарантий, валютных рисков и траншей. Это не финансовое заключение.
- API, онлайн-поиск и шрифты могут требовать интернет; сам интерфейс, SQLite и расчётные Python-модули могут работать локально.
- Автоматизированные проверки ядра и API пройдены. В этой среде интерактивный браузер блокировал открытие локального сервера, поэтому ручную визуальную проверку в браузере **нужно выполнить на Windows**.

## Структура файлов

```text
TenderMind_AI_Fullstack_v2/
  START_WINDOWS.bat      запуск одним двойным щелчком
  run.py                 локальный Python-сервер + открыть браузер
  server.py              FastAPI API, адаптер старой SQLite-схемы
  core/                  прежние Python-движки, без Streamlit
  web/
    index.html           HTML интерфейс
    styles.css           современное оформление
    app.js               навигация, графики, проекты
    integration.js       вызовы AI, поиска, оптимизатора и CashGuard
  data/                  пример тендера и тестовые цены; создаёт SQLite
  tests/                 тесты ядра и API
  requirements.txt
  .env.example
```

**Запуск тестов:** `uv pip install --python .venv\Scripts\python.exe pytest httpx`, затем `.\.venv\Scripts\python.exe -m pytest -q tests`.

## Обновление интерфейса v2.2

- **Главная:** новый градиентный баннер, блоки ключевых показателей из SQLite, подсказки по следующему шагу и быстрые переходы к функциональным страницам.
- **Тёмная тема:** непрерывная анимация фиолетового, бирюзового и зелёного оттенков с полупрозрачными карточками. Для `prefers-reduced-motion` анимация отключается.
- **Светлая тема:** мягкие разноцветные фоновые подсветки и более заметные границы, объёмные карточки и закругления.
- **RU / KZ / EN:** переключатель в верхней панели и выпадающий список «Выбор языка» в настройках. Язык и тема сохраняются в локальных настройках браузера. Интерфейсные тексты переведены без изменения ID, категорий, пользовательских данных, числовых значений и сохранённых тендеров. Данные тендеров и ответы AI остаются на языке оригинала; отдельные сообщения сервера также могут возвращаться на русском.
- **Совместимость:** Python API, OpenAI/Gemini, Supplier Hunter, SmartMatch, SplitBuy, CashGuard, импорт/экспорт и прежний формат SQLite сохранены. Перед обновлением проекта скопируйте `data/projects.sqlite3` и `.env` из старой папки (при наличии).
- **Запуск:** `START_WINDOWS.bat` дополнительно проверяет стандартные пути к uv после установки через winget.

Визуальный интерфейс можно просматривать только при запущенном Python-сервере. `index.html` отдельно не является полнофункциональной версией.
